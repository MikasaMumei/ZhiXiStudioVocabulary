# 使用指南

## 建立自己的词表

第一次安装是空库。从首页新建书本，或从“批量导入”下载原创示例 CSV／上传自己的 Excel。填写明确的书本编号、教材版本和册次；未知信息保留“未核实”，不要把来源不明的词表当成新版教材。

导入流程为：上传 → 映射字段 → 预览差异 → 确认导入。支持多文件和 Excel 工作表选择；相同文件重复导入不会重复添加。缺少释义可先保存、稍后补全；正式生成资料前需有可用中文义。

## 校订和分组

书本页按单元、首字母 A–Z、关键词与校对状态筛选。编辑课程词条时，默认只改变这本书的课程值。基础词典的通用资料与课程义分开，不把不同教材的多义词强行合并。

无单元的资料可归入“未分单元”，再通过勾选或整书行号范围批量分组。行号从 1 开始，按整本书原序计算，不受当前筛选影响。单元设置可修改名称和顺序；不要把临时复习组冒充教材单元。

需要混合复习时，先新建自编词表，再复制所选课程词条。复制保留当时的内容，不自动随来源更新。归档词条可通过“已归档”筛选后恢复。

批量编辑建议先从书本导出 Excel，保留条目 ID 和修订号，修改后重新导入。旧导出表不能覆盖网页上的新修改，系统会提示冲突。

## 生成三张表

1. 在书本页使用“生成当前筛选范围的 PDF”，或勾选部分词条后打印。
2. 也可从“打印资料 → 生成新资料”按复选框选择整书或单元，支持跨书组合。
3. 查看缺失项和重复提示，再设置标题、分组、顺序、字体与行距。
4. 生成后预览或下载中英对照、看英写中、看中写英，或一次下载三份 PDF 的 ZIP。

三表编号对应同一词条，但分页可不同。看英写中固定显示英文和音标，留中文填写区；看中写英默认不提示音标，可选音标提示双栏。短语没有音标正常留空，不需要额外确认。更多版式说明见 [PDF 排版](printing.md)。

## 管理打印资料

资料页支持名称搜索和分页，每页 24 份。勾选后可批量删除，详情页也有“删除这份资料”。确认页列出本次处理范围；删除后移入回收站，不会删除词库或已下载的 PDF。

回收站可单份或批量恢复，不自动清空，也没有永久删除入口。恢复后继续使用同一份快照和编号。回收站内资料的下载链接暂时停用，恢复后重新可用。

详情页可“修改显示名称”，用于整理列表。PDF 内标题及内容保持生成时的版本；需要修改打印标题或词条时，请重新生成。若旧页面期间发生改名、删除或恢复，提交时会提示刷新；批量操作不只完成一半。

## 保存与备份

PDF 自带中文和音标字体，保存后可长期独立使用。词库更新不会覆盖已生成内容；旧版已下载文件不会自动更新。

Excel 导出和 PDF 不能替代完整备份。请按 [部署维护](operations.md) 备份 PostgreSQL 并验证恢复，保留对应应用版本和私有配置。
