# PDF 排版与资料版本

## 三张表

| 模式 | 默认结构 |
| --- | --- |
| 中英对照 | 双栏，每栏：英文／美音／中文义 |
| 看英写中 | 双栏，每栏：英文／美音／中文填写区 |
| 看中写英 | 三栏，每栏：中文义／英文填写区；可选双栏音标提示或单栏 |

三种资料使用相同的词条编号，但栏数和分页可以不同。中英对照可用于核对两种练习，题目中不包含隐藏的答案文字。缺美音时留空，短语不要求补音标。

支持原序、字母序或固定种子乱序，按单元、首字母分组或合并连续排版。组内乱序保留分组边界，分组可选择另起页。

## 纵向填栏与横线对齐

模板 2.3 先使用实际 PDF 引擎和内置字体测量每条内容，再计算每页容量、将词条均分为纵向栏，最后转成一张共享行高的表格。四条的顺序为左栏 1、2，右栏 3、4；每页各分组的栏内数量最多相差一条。

左右对应行取最高单元格的高度。长词、音标、释义或例句换行后，左右横线仍然对齐，整条不拆开，空缺位置保留空白网格。分组标题与表头在续页重复。共享行高可能比独立分栏多占一些纸张，优先保证阅读和填写整齐。

看英写中各栏宽度为英文 44%、音标 27%、填写区 29%；中英对照为 40%、27%、33%。不缩小字体强行塞下长词，必要时正常换行。

## 下载与保存

- 单份 PDF 自带字体，可直接打印或永久保存，无需 assets 文件夹。
- PDF ZIP 包含三份 PDF 和说明，不另附教师答案。
- “预览 PDF”与下载采用同一排版过程。
- 高级 HTML 内容归档含源稿、快照与字体，未包含 PDF 引擎测量产生的分页网格；正式打印以 PDF 为准。

建议 A4、100%／实际大小。PDF 引擎只允许读取两份内置字体，不读取任意网址或宿主文件；生成过程不调用外部服务。同一实例串行生成 PDF，忙碌时提示稍后重试，单次总超时为 90 秒。大份资料建议分单元或单份下载。

## 历史资料

生成时冻结词条、有效课程义、排序、选项和 HTML 源稿。修改词库不会覆盖旧内容；修改显示名称也不会改变 PDF 内标题。删除只移至回收站，恢复后沿用同一份快照。

旧模板保留原排版。旧“看音写中”标记在已知标题位置会显示为正确的“看英写中”，不回写词条、源稿或校验值。已下载的旧文件需要重新下载才能显示纠正名称。

源稿校验值用于标识冻结内容，不保证未来导出的 PDF 字节完全一致。分页还依赖排版引擎和字体；需要长期固定版面时，保存已生成的 PDF。
