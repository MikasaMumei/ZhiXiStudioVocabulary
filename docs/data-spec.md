# 数据与导入规范

## 数据分层

基础词典 → 书本／章节 → 课程条目 → 打印快照。同词在不同书本可以使用不同课程义、读音和例句。打印有效值优先使用课程条目的明确覆盖值，其次为基础词典值；空白和继承不是同一个含义。

| 数据表 | 职责 |
| --- | --- |
| terms | 拼写、词／短语类型、通用释义、美音、英音、例句、来源和修订号 |
| books / sections | 教材版本、学段、年级、册次、章节及顺序 |
| book_items | 课程义和读音覆盖、章节位置、校对状态、来源与修订号 |
| sources / import_batches | 来源、原始文件归档、字段映射、差异计划和导入结果 |
| print_jobs | 显示名称、内容快照、冻结 HTML、校验值、回收站时间和管理修订号 |

数据库使用 PostgreSQL、外键约束和事务。可变字段来源、导入计划和快照使用 JSONB；原始上传归档存入数据库，便于一致性备份。

## 导入字段

支持 `.xlsx` 与 UTF-8 CSV。导入向导可映射列名，默认 Excel 工作表为 `words`。

| 字段 | 说明 |
| --- | --- |
| 单词 | 必需；允许短语，保留大小写、标点和词形 |
| 美音、英音 | 分别保存；地区不明的读音不得标为美音 |
| 中文释义、词性 | 课程所需含义；生成正式资料前需有可用释义 |
| 单元、顺序 | 缺单元时归入“未分单元”；缺顺序时按导入行序 |
| 例句、例句翻译 | 可选 |
| 书本编号、书名、学段、年级、出版社、教材版本、册次 | 可在表中提供，或在向导统一填写 |
| 来源、备注 | 记录取得依据及人工说明 |
| 条目 ID、修订号 | 导出时附带，重新导入用于准确更新和冲突检测 |

建议先下载[原创示例](../englishwords/static/sample.csv)试用。旧 `.xls`、扫描 PDF、OCR 和图片提取不在本项目范围内。

## 更新规则

- 相同文件和映射重复导入，不重复写入。
- 有条目 ID 时核对所属书本和修订号，过期修改拒绝应用。
- 无 ID 的新表只作保守匹配；重复词形或多义项不静默合并。
- 默认新增和补充空白；覆盖非空字段需预览后明确选择。
- 导入表缺少的旧行不自动删除。归档与恢复通过独立操作完成。
- 一次确认作为一个事务，发生错误全部回滚。
- 复制到复习词表会保留选入时的课程值，不自动跟随原词条更新。

## 教材与读音来源

教材版本、册次和分单元依据必须可追踪；不根据文件名猜版次，不均分词条冒充真实单元。未核实信息明确标注，未知美音留空。短语没有音标是正常情况。

只做 Unicode 规范化及首尾空白清理，不随意还原词形、删除标点或合并大小写。公开程序与教学内容分开：本仓库不提供课本全量词表、商业词典内容或私人数据。
